# examen_algebra_lineal
Repositorio exclusivo para el desarrollo del examen de Algebra Lineal del curso de Herramientas Matemáticas y Computacionales para la IA.

## Reglas generales

Cada estudiante deberá trabajar exclusivamente en la rama asignada para la evaluación.

1. Clonar el repositorio.
2. Cambiar a examen_1.
3. Actualizar examen_1.
4. Crear una rama apellido1_apellido2.
5. Resolver exclusivamente regression_exam.py.
6. Realizar al menos dos commits.
7. Hacer push de la rama individual.
8. NO crear Pull Request.
9. NO hacer merge.
10. NO modificar examen_1 ni main.
